## 1. Beginner-Friendly Code Generation

```text
Act as a professional software developer and B.Tech IT professor.

Write a program in [PROGRAMMING LANGUAGE] to solve the following problem:

[PROBLEM]

Requirements:
1. Use simple and beginner-friendly code.
2. Explain the code step by step.
3. Add comments where necessary.
4. Show the expected output.
5. Explain the important concepts used.
6. Mention common mistakes beginners may make.

Do not use unnecessarily advanced concepts.
