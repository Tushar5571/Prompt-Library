# ✈️ Travel Planner Prompt Library

This file contains reusable prompts for planning trips, creating itineraries, managing travel budgets, and getting travel recommendations.



## 1. Complete Trip Planner



Act as a professional travel planner.

Plan a trip to [DESTINATION] for [NUMBER OF DAYS] days.

My starting location is [STARTING LOCATION].
My budget is [BUDGET].
Number of travelers: [NUMBER OF PEOPLE].
Travel style: [BUDGET/MID-RANGE/LUXURY].

Include:
1. Day-by-day itinerary
2. Places to visit
3. Transportation options
4. Hotel or accommodation suggestions
5. Food recommendations
6. Estimated daily cost
7. Important travel tips
8. Things to avoid
9. Output Format

Present the answer in a simple way
