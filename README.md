# 🤖 Prompt Library

## 📌 Introduction

This repository contains a collection of reusable AI prompts created for different tasks.

The purpose of this Prompt Library is to understand **Prompt Engineering** and learn how clear and well-structured prompts can improve the quality of AI-generated responses.

---

## 🧩 Prompt Structure

A well-designed prompt generally contains:

**Role + Task + Context + Requirements + Output Format**

For example:

> Act as a B.Tech IT professor.
> Explain the topic "Artificial Intelligence".
> Assume that I am a beginner.
> Give simple examples and important exam points.
> Present the answer using headings and bullet points.
