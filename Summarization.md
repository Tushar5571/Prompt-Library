# 📝 Summarization Prompt Library

This file contains reusable AI prompts for summarizing articles, study material, long text, documents, and other content.

---

## 1. General Text Summarization

```text
Act as an expert summarizer.

Summarize the following text:

[PASTE TEXT]

Requirements:
1. Identify the main idea.
2. Extract the most important points.
3. Remove unnecessary information.
4. Keep important facts and examples.
5. Use simple and clear language.
6. Present the summary using bullet points.
7. Give a short conclusion.

Do not add information that is not present in the original text.
